# MenuPocket 使用教程

## 1. 安装与授权

从 [GitHub Releases](https://github.com/codeleep/MenuPocket/releases) 下载 Universal DMG，打开后将 `MenuPocket.app` 拖到 `Applications`，再弹出磁盘映像，从「应用程序」启动。安装包支持 Apple Silicon 和 Intel，无需编译。已有旧版时先退出再替换，配置保留在本机。也可以按 [构建教程](BUILDING.md) 自行编译。

当前版本未做 Apple 公证。若提示开发者无法验证，确认下载来源后，先尝试打开一次，再到「系统设置 → 隐私与安全性」选择该应用的「仍要打开」，参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。如系统提示恶意软件或文件损坏，请停止并检查来源和下载完整性。

在管理窗口「权限与说明」中打开系统设置，为 MenuPocket 开启辅助功能。这项权限用于发现、点击和移动其他应用的菜单栏图标。没有授权时不会正常读取和操作图标。

屏幕录制是可选权限，只用于读取对应图标窗口的图片；不开启时使用应用图标或系统符号。图片只在内存中使用。首次授权后返回应用刷新；必要时退出后重新启动。

## 2. 创建和整理分组

点击左下角「新建分组」，输入名称。拖动图标卡片到左侧分组，也可以点击卡片，在图标设置中选择目标组。组内位置通过「前移」「后移」调整。

![管理界面，演示数据](images/01-management.png)

分组可以改名、调整顺序、隐藏和删除。隐藏组会移除菜单栏中的组入口，仍可从「全部图标」访问和恢复。删除组会把其中图标移入未分组，不会退出对应应用。

菜单栏空间仍由 macOS 决定，建议控制组数量并缩短组名。全部图标入口和快捷键可以访问已识别但组入口没有显示出来的项目。

## 3. 设置每个图标的显示位置

点击管理界面中的图标，打开设置：

| 选项 | 预期行为 |
| --- | --- |
| 菜单栏和分组都显示 | 保留原生入口，并可从分组访问 |
| 仅在分组显示 | 尝试隐藏原生入口，仅从分组访问 |

![单图标设置，演示数据](images/02-icon-settings.png)

设置会自动保存。请同时查看结果文字：偏好保存成功不代表原生图标已经隐藏。定位失败或系统不接受移动时，会显示失败原因，可在刷新后重试。无法操作的图标建议保留在菜单栏。

修改显示偏好只重新处理当前图标；分组内排序不触发全量移动。底层移动时共享的不可见占位会短暂缩短，其他隐藏图标可能闪现。启动、显示器变化或分组入口结构变化可能触发完整布局。

## 4. 日常使用

点击菜单栏组名打开小悬浮面板，点击其中图标访问原应用菜单。点击面板外部或再次点击同一入口即可关闭。

![日常分组面板，演示数据](images/03-quick-panel.png)

按 **Control + Option + Command + B** 打开全部图标面板。面板右下角齿轮进入管理界面；右键图标的「图标设置…」进入该项设置。重新从 Finder 打开 MenuPocket 也可以进入管理界面。

原应用菜单仍锚定在其原生菜单栏位置。隐藏后的菜单访问依赖应用实现，尚未逐项完成验证。

## 5. 常见问题

### 5.1 设置了隐藏，原图标还在

先查看图标设置中的实际结果，再刷新并重试。时钟、控制中心等项目可能拒绝移动；部分第三方应用返回的辅助功能位置与真实窗口不一致。MenuPocket 不会把事件发送成功当作隐藏成功。详见 [兼容性记录](../VERIFICATION.md)。

### 5.2 升级后辅助功能失效

确认运行的是刚更新的应用。签名身份或安装路径改变时，macOS 可能需要重新授权：退出应用，在辅助功能列表移除旧条目，再添加当前应用。开发时保留 `.local-signing/`，不要在同一路径反复切换本地签名和临时签名。

### 5.3 图标缺失、重复或显示为控制中心

先刷新，确认对应应用仍运行。macOS 可能由控制中心代管第三方图标窗口，MenuPocket 会尽量按源应用和窗口去重，但不同系统仍可能存在差异。提交问题时附系统版本、应用版本、显示器情况和实际结果，避免直接上传完整诊断文件。

### 5.4 如何备份和卸载

配置位于 `~/Library/Application Support/MenuPocket/layout.json`。退出应用后复制该文件即可备份。恢复前先备份现有配置，并使用兼容版本。

卸载时先退出 MenuPocket，释放内部占位，再删除应用。需要彻底移除本机配置时，可在 Finder「前往文件夹」打开上述目录并手动删除。开发签名目录可能用于继续构建，应单独保管。

## 6. 数据与隐私

应用不联网。布局和诊断保存在本机 Application Support 目录；`visibility-diagnostics.json` 与 `scan-diagnostics.json` 可能包含应用标识及窗口位置，不含屏幕图片。公开反馈前应删除个人应用信息。截图教程中的界面使用演示数据，与实际用户列表隔离。
